About this solver

    
The solver code is written in C++ and compiled to WebAssembly, so it runs entirely in your browser. The same sources build the command-line binaries; results are reproducible for a given seed on the same version. Costs are total latency (the sum of customer arrival times). Gap to BKS is 100 * (cost - BKS) / BKS, using the best known solution in the instance file.

    
Time estimates come from a fitted model on benchmark runs and are only indicative (roughly +/- 50%). Actual time depends on your device.
